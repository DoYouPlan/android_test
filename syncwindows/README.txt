ХРЮШКИНЫ ПОДУШКИ · БУХГАЛТЕРИЯ 3.0

ЗАПУСК
Распакуйте архив и запустите Hryushki_Accounts.exe. Python не требуется.
Использует встроенный в Windows 10/11 .NET Framework 4.x.
Папку PluginSDK для обычного учёта открывать не нужно.

ОБНОВЛЕНИЕ С 2.1
Сначала скопируйте свою базу hryushki_accounts_data.json в безопасное место.
Можно положить её рядом с новым EXE — приложение откроет её при запуске.
Либо выберите «База и копии → Открыть JSON». Выбранный файл будет рабочим:
все изменения сохраняются в него. Вторая копия программы с той же базой
блокируется. Если база изменена извне, сохранение блокируется до переоткрытия.
Формат JSON version=2 сохранён, добавлены служебные поля для истории и оплаты.
Каталог и неизвестные дополнительные поля сохраняются.
Не открывайте одну рабочую базу одновременно в старой версии или Android.

НОВЫЙ ИНТЕРФЕЙС
Зелёная боковая панель, карточки показателей, журнал с поиском и периодом,
отдельные разделы складов, товаров, материалов и плагинов.
Ctrl+N — новая операция; F5 — обновить раздел.
Поиск фильтрует текущую таблицу. CSV выгружает только её видимые строки.

УЧЁТ
Сумма операции — за всё количество, не цена за единицу.
Продажа списывает изделие со склада. Полученная оплата указывается отдельно
от выручки; остаток образует долг покупателя или партнёра. Комиссия уменьшает
долг к перечислению и включается в расходы. Выплата партнёра погашает долг,
не создаёт вторую выручку. Для погашения долга покупателя применяется тот же
тип «Выплата партнёра» с именем покупателя в поле контрагента.
Передача/возврат от партнёра перемещают запас между Домом и выбранным складом.
Производство увеличивает количество изделий. Сумма производства не списывает
деньги автоматически: затраты должны входить в себестоимость изделий.
Себестоимость в карточке подставляется только в НОВЫЕ продажи. В продаже
можно уточнить полную себестоимость всей строки или оставить её неизвестной.
Старые продажи не пересчитываются по новой стоимости карточки.
Неизвестная себестоимость явно отмечается: результат предварительный.
Вложения и вывод владельцу не меняют результат, но меняют движение денег.
«Поступление» — прочий доход; поступление с категорией, содержащей «партн»,
сохраняет историческое значение выплаты партнёра.

МАТЕРИАЛЫ
Карточка материала содержит начальное количество, единицу и справочную цену.
Покупка материалов увеличивает количество и уменьшает движение денег.
Расход материалов уменьшает количество. Закупка не вычитается повторно из
результата: стоимость материалов вручную включайте в себестоимость продажи.
Автоматических рецептур, раскроя и оценки незавершённого производства нет.
Нельзя переименовать материал/изделие с операциями: создайте новую карточку.

ПОКАЗАТЕЛИ
Выручка, расходы и расчётный результат относятся к выбранному периоду.
Долги и остатки рассчитываются накопительно на дату окончания периода.
Чистое движение денег показано за всю историю до даты окончания, а не за
выбранный период. Без полного начального баланса это не остаток на карте.
Записи «Без даты» сохраняются: количество учитывается как начальный остаток,
в конкретный период денежного отчёта такие записи не входят.
Старые отрицательные остатки не исправляются выдуманными приходами: они
видны в разделе «Нужно сверить». Новые действия не могут ухудшить нехватку.
Для изменения записи выберите её в журнале. Предыдущее состояние сохраняется
в _audit. Отмена требует причину; запись остаётся в журнале с _void=true.
Реальные возвраты покупателей, предоплаты и налоговая отчётность в 3.0 ещё
не реализованы. Отмена ошибки ввода не заменяет реальный возврат.

КОПИИ И ANDROID
Перед сохранением создаётся автоматическая копия рядом с базой, в backups.
Хранятся последние 30 состояний. Сохраняйте дополнительные копии на иной диск.
«Восстановить» заменяет рабочую базу выбранной копией после подтверждения.
Обычная резервная копия содержит полную историю изменений.
«Экспорт JSON» для Android исключает отменённые записи. Android 1.0 ещё не
понимает частичные оплаты, комиссии, себестоимость и часть новых типов — его
показатели для таких операций могут отличаться. Это перенос файла, не синхронизация.
Не заменяйте рабочую базу устаревшей копией с другого устройства.
Если рядом с EXE нет базы, используется %LOCALAPPDATA%\HryushkiAccounts3.
Последний открытый файл запоминается; приоритет у базы рядом с EXE.

ПЛАГИНЫ
Раздел «Плагины»: установить ZIP, включить, запустить, выключить, удалить.
API 1 предназначен для дополнительных отчётов по снимку базы.
Кода для будущих бизнес-плагинов нет; поставляется только демонстрационный
отчёт ExampleReport.zip для проверки и шаблон разработки в PluginSDK.
Пример не установлен автоматически. Обычное приложение работает без плагинов.
Запуск — отдельный процесс с тайм-аутом 15 секунд. Это изоляция сбоев,
не песочница: доверенный плагин имеет права текущего пользователя.
Новые операции через API плагина в версии 1 недоступны. Подробности в PluginSDK/README.md.

# Плагины Хрюшкины подушки · API 1

Пакет ZIP содержит в корне `plugin.json` и одну или несколько управляемых DLL .NET Framework 4.5. Папки и произвольные файлы не допускаются. Максимум 100 файлов и 10 МБ в распакованном виде. Допускаются .dll, .json, .txt, .md.

Класс из `entryType` реализует публичный интерфейс из Hryushki_Accounts.exe:

```csharp
public interface IAccountsPlugin {
    PluginReport Execute(string databaseJson);
}
```

`PluginReport` содержит `Title`, `Summary`, `string[] Columns`, `List<string[]> Rows`. До 30 столбцов, 10000 строк, до 1 МБ итогового JSON. Число ячеек в каждой строке должно совпадать с числом столбцов.

При компиляции сослаться на Hryushki_Accounts.exe версии 3.0 и System.Core.dll. Пример и манифест находятся рядом. Готовый ExampleReport.zip устанавливается через раздел «Плагины». После установки включить и нажать «Запустить».

Пример компиляции штатным C#-компилятором Windows, из папки программы:

```bat
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /target:library /out:ExampleReport.dll /r:Hryushki_Accounts.exe /r:System.Core.dll ExampleReport.cs
```

`apiVersion` равен 1, `id` — уникальный идентификатор 3–64 символа: строчные латинские буквы, цифры, точка, дефис, подчёркивание. Идентификатор начинается с буквы и не содержит `..`. `assembly` — имя DLL без пути, `entryType` — полное имя класса.

При запуске передаётся снимок ВСЕЙ базы, не только выбранного периода. Плагин не получает объект хранилища или API для записи операций. Поле `_void: true` означает отменённую операцию. Не включайте её в отчёт. Суммы `amount` — за всю строку, дата `dd.MM.yyyy`; исторические записи бывают `Без даты`. Формат JSON остаётся version=2, дополнительные служебные поля сохраняются.

Каждый вызов работает в отдельном процессе, тайм-аут 15 секунд. Ошибка возвращается в интерфейс. Это защита приложения от большинства сбоев, а НЕ песочница: DLL имеет права пользователя, включая доступ к файлам и сети. Ставить только доверенный код. Никакой удалённой загрузки и автозапуска нет. После установки выключен; выполнение только кнопкой «Запустить». Подмена API/бинарного файла программы плагином не поддерживается.

Для обновления удалить старый пакет и установить новый. Папка плагинов: `%LOCALAPPDATA%\HryushkiAccounts3\plugins`. Настройка включения хранится в enabled.json. Программные зависимости .NET и собственные ресурсы должны поставляться в рамках перечисленных ограничений; зависимости, требующие Python, Node или нативные библиотеки, в API 1 не поддержаны.

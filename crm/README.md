# Хрюшки · Заказы 1.0

Отдельное локальное Android-приложение для клиентов, заказов и пожеланий мастерской «Хрюшкины подушки». Android 8.0 и новее. Работает без сервера и интернета. База бухгалтерии не изменяется.

## Первое использование

1. Установите подписанный `Hryushki_Clients_Orders_1.0.apk`.
2. На экране «Сегодня» нажмите «Новый клиент». Заполните имя, город, канал ВК / Авито / Другое и контакт для себя. Приложение не отправляет сообщения клиентам.
3. В карточке клиента создайте заказ либо пожелание / предзаказ.
4. В «База и настройки» разрешите уведомления, нажмите «Проверить уведомление» и убедитесь, что оно появилось.
5. Регулярно экспортируйте JSON на другое устройство. Внутренние копии удаляются при удалении приложения.

## Клиенты и заказы

В карточке клиента: имя, город, основной канал заказа, контакт (ссылка, ник или телефон), заметки и архив. Из карточки доступны все его заказы и пожелания.

В заказе: канал конкретного заказа, дата оформления, срок отправки, фактическая отправка, ожидаемая доставка и фактическое получение. Состав — несколько позиций с названием, артикулом, тканью / цветом, размером, количеством и ценой за штуку. Дополнительно: стоимость доставки, предоплата, остаток к оплате, перевозчик, трек-номер и заметки.

Статусы: «Новый», «Шьём», «Готов к отправке», «Отправлен», «Доставлен», «Отменён». Фактическая отправка обязательна для отправленного заказа; фактическое получение — для доставленного. Заказы и клиенты не удаляются бесследно: завершённые заказы доступны через фильтр, клиенты — через архив.

Суммы заказа справочные. Они не создают продаж и поступлений в приложении бухгалтерии, не списывают склад. Для учёта денег и изделий используйте бухгалтерию отдельно.

## Срок отправки

По умолчанию дата оформления + 3 календарных дня, до 18:00 местного времени телефона. Например, оформление 2 ноября → отправка до 5 ноября 18:00. Это не правило «72 часа от нажатия кнопки»: дата оформления хранится без времени. У каждого заказа срок можно изменить вручную. После изменения оформления нажмите «Пересчитать срок от даты оформления» либо укажите срок сами.

На экране виден обратный отсчёт до срока отправки. Просроченные заказы поднимаются в начало списка «Сегодня». Отсчёт на открытом экране обновляется каждые 30 секунд.

Число дней для новых заказов и часы напоминаний / окончания срока настраиваются. Изменение числа дней в настройках не переносит даты уже созданных заказов.

## Напоминания

- Накануне отправки — проверьте готовность.
- Утром в день срока — пора отправить.
- При просрочке — ежедневно, пока заказ не отправлен или не отменён.
- Ожидаемая доставка — одно уведомление в указанную дату, чтобы проверить получение. Фактическое получение отмечается вручную.
- Пожелание — одно уведомление в выбранную дату связи.

По умолчанию уведомления назначены на 09:00 по времени телефона. Даты доставки и связи необязательны: без них соответствующее уведомление не назначается. Изменение даты заменяет событие, старое уведомление отменяется. При отправке прекращаются напоминания об отправке, при получении или отмене — оставшиеся напоминания по заказу.

Для работы нужно разрешить уведомления, включая канал «Заказы и пожелания». Android может задерживать фоновые уведомления при экономии энергии; это не точный будильник. Для этой версии не нужно отдельное разрешение на точные будильники. После перезагрузки телефона / смены часового пояса расписание пересчитывается. После принудительной остановки через системные настройки приложение нужно снова открыть. Внутренний экран «Сегодня» доступен независимо от разрешения уведомлений.

Уведомления на экране блокировки скрывают подробности, если телефон поддерживает и соблюдает настройку приватности уведомлений.

## Пожелания и предзаказы

Пожелание содержит тип, изделие, артикул (если известен), цвет, размер, количество, заметку и необязательную дату связи. Статусы: «Ожидает», «Есть в наличии», «Клиенту сообщили», «Заказ создан», «Отменено».

Пожелание не запускает срок отправки. Через поиск по цвету / изделию / артикулу можно найти клиентов, которым обещали написать. Наличие и факт общения отмечаются вручную: связи со складом, ВК и Авито в этой версии нет.

«Создать заказ из пожелания» создаёт один подтверждённый заказ с текущей датой и новым сроком, копирует состав и связывает его с исходным пожеланием. Повторное открытие показывает ссылку на созданный заказ. Проверьте цены: при переносе они не подставляются автоматически и остаются несогласованными.

## Хранение и перенос

Изменения сохраняются внутри приложения автоматически. Есть 20 внутренних резервных копий, полный JSON для переноса и CSV клиентов, заказов и пожеланий с учётом поиска / фильтра. Последние 500 действий сохраняются в истории. Импорт JSON заменяет базу целиком после подтверждения; перед заменой создаётся копия. Это не объединение двух баз и не синхронизация.

База клиентов имеет свой формат и не принимает JSON из бухгалтерии. При ошибке чтения сохранённая база не заменяется пустой: открывается экран восстановления и выгрузки исходного файла.

## Сборка

Java 17, Gradle 8.9, Android Gradle Plugin 8.7.3, SDK 35.

`gradle -p crm :app:assembleDebug :app:assembleRelease :app:assembleDebugAndroidTest`

CI использует временную отладочную подпись для тестов и установки. Готовый пользовательский APK подписывается постоянным ключом вне репозитория. Личные данные клиентов, базы и ключ подписи в исходники не включаются.
